What you can do

A pure-JS frontend that enables or disables each action based on your current user's OpenFGA permissions, fetched from GET /mvc/me. Sign in as different demo users (dave, carol, bob, alice) to watch the buttons switch on and off — locked ones (🔒) name the permission you'd need. Any authenticated user can open this page.

How it works

The API returns the permissions you hold as "action:resource" strings. The frontend hardcodes no roles — it just checks membership with a one-line helper.

GET /mvc/me → response 
{
  "user": "carol",
  "permissions": ["read:posts", "create:posts"]
}
wwwroot/permissions.js 
// 1. Ask the API which permissions the current user holds
const res = await fetch("/mvc/me");
const { permissions } = await res.json();

// 2. A generic helper — no roles baked into the frontend
const can = (perms, p) => perms.includes(p);

// 3. Turn UI on/off by permission
newPostButton.disabled = !can(permissions, "create:posts");
adminLink.hidden       = !can(permissions, "manage:access");
