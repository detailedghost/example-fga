Access — pure-JS frontend

This page is plain static HTML + vanilla JavaScript — no framework, no server rendering. It reads the role matrix from GET /api/access and flips roles on/off by calling the same /api/access/grant and /api/access/revoke endpoints (minimal API), all backed by the selected authorization provider. Changes here show up in the server-rendered /Admin/Access page too — same store. Sign in as an admin (e.g. alice) to use it.
