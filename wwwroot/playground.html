FGA Playground — local

The seeded store, read live from the OpenFGA API. This replaces the bundled :3000/playground, which is an iframe of the hosted play.fga.dev — a public HTTPS page, so Chrome's Private Network Access policy blocks it from calling 127.0.0.1:8080 and it never sees your store. This page is served from localhost, so that block doesn't apply. It is available only when AUTHORIZATION_PROVIDER=openfga. Sign in (e.g. alice) to load it.
